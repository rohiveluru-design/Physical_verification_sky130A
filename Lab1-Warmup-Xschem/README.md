# Lab 1: Warmup and Xschem

## Objective
Design and simulate a CMOS inverter using the SKY130A PDK.

## Tools
- Xschem
- ngspice
- SKY130A PDK

## Work Completed
- Created the CMOS inverter schematic.
- Ran a DC sweep simulation.
- Observed the inverter voltage transfer behavior: the output voltage decreases as the input voltage increases.

## Files
- `inverter.sch`: Xschem schematic
- `simulation/inverter.spice`: Generated SPICE netlist
- `screenshots/`: Schematic and simulation graph evidence
